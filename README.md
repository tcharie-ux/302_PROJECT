# Building Design & Cost Estimation Platform

## Présentation

Building Design & Cost Estimation Platform est une plateforme web dédiée à la conception virtuelle de bâtiments et à l'estimation des coûts de construction.

Le projet vise à faciliter la collaboration entre les différents acteurs d'un projet de construction et à permettre une meilleure visualisation du projet avant sa réalisation.

## Objectifs

- Faciliter la conception virtuelle des bâtiments
- Permettre la réalisation de modèles 2D
- Faciliter la visualisation en 3D
- Centraliser les informations liées aux projets
- Contribuer à l'estimation des matériaux et des coûts
- Faciliter la collaboration entre les utilisateurs

## Architecture

Le projet est organisé autour de deux parties principales :

- **Backend** : API et logique métier développées avec Spring Boot
- **Frontend** : interface utilisateur développée avec Angular

## Fonctionnalités principales

- Gestion des utilisateurs
- Gestion des projets

- Visualisation 3D
